## Purpose

How-to guides in this section are:

- Task-oriented
- Goal-driven procedures
- Practical step-by-step instructions
- Focused on solving specific problems
- Written for users who have basic knowledge

Each how-to guide should:
- Address a specific goal or problem
- Provide a series of steps to achieve that goal
- Focus on practical results rather than learning
- Be written in an imperative style ("Do this, then do that")
- Include troubleshooting sections for common issues

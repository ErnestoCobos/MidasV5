## Purpose

Tutorials in this section are:

- Learning-oriented
- Focused on practical lessons
- Designed for beginners
- Follow a step-by-step approach
- Allow the user to learn by doing

Each tutorial should:
- Have a clear goal that the user will achieve
- Start from zero knowledge about the specific task
- Include all steps needed to complete the goal
- Provide working examples that can be run as-is

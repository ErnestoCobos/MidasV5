# Badges

This directory contains automatically generated badges and metrics for the MidasTS project.

## Available Badges

- `coverage.svg` - Test coverage badge
- `build-status.svg` - CI build status badge
- `version.svg` - Current version badge

## Usage

These badges can be included in documentation or the project's main README using markdown:

```markdown
![Coverage](./badges/coverage.svg)
![Build Status](./badges/build-status.svg)
![Version](./badges/version.svg)
```

## Generation

Badges are automatically generated by the CI/CD pipeline on each push to main. To manually generate them:

```bash
# Generate coverage badge
npm run coverage:badge

# Generate version badge
npm run version:badge
```

## Scripts

The badge generation uses the following scripts:

- `scripts/generate-coverage-badge.js` - Generates coverage badge from test results
- `scripts/generate-version-badge.js` - Generates version badge from package.json

## Purpose

Explanations in this section are:

- Understanding-oriented
- Theoretical rather than practical
- Providing background and context
- Discussing concepts and relationships
- Written to illuminate and educate

Each explanation should:
- Be concept-focused rather than action-focused
- Provide the "why" behind design and implementation decisions
- Connect different parts of the system to show how they work together
- Include diagrams and visual representations of complex concepts
- Be written in a clear, educational style
- Avoid procedural steps (those belong in tutorials or how-to guides)
